## 公开代码草稿对照

`free_codegen.py` 是独立的公开研究工具，生产服务不导入它。它只接受实时目录中输入、输出和请求价格均为零的具名 `:free` 模型，并设置零价格上限、关闭回退；缺少密钥、限流或费用不明时停止。当前未发起模型生成请求。输出仅保存为草稿，不应用或执行；它没有实现完整自动编程 Agent，也没有得到配对解题成绩。

`local_codegen.py` 与 `run_local_paired_codegen.py` 另行准备本机开源模型的两份草稿。它们使用同一原始源码与任务，显式缩小历史上下文预算，不会把草稿自动写进目标仓库。`evaluate_local_sympy_pair.py` 仅评估已开发过的公开 SymPy 案例，要求两份输出已冻结、经当前助手审核，并在代码冻结后才读取公开测试补丁。它不是生产组件或通用官方编程 Agent。


本地模型路径现已执行两轮 GPU 草稿及实际测试，两个分组在两轮中均失败。没有外部模型调用。`prompt_layout.py` 是第二轮公开开发试验的提示词排列，生产服务不导入；不是官方 Answer 契约。详情和异常保留见 docs/本地模型对照.md。申请和 Smoke 已获授权，Full 继续关闭。
