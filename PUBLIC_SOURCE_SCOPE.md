# Public source scope

This branch contains the current Coding service, development tools, learning documents and reports.
It is separate from the repository's frozen Textual default branch. No Coding deployment, application,
Smoke pass, Full run or competition score is claimed by publishing source.

Historical binary source snapshots, full tuning reports and the built wheel are retained in the local learning package;
they are not uploaded in this text-only branch. Old reports refer to their original frozen code, not
automatically to current code. Three early report source snapshots are incomplete, as disclosed locally.
Current service and tests can be reproduced directly from this branch. Abandoned BGE helpers, model
weights, datasets, databases, logs, target test-oracle patches and credentials are excluded.

The user permits application and Smoke. Full remains disabled.
