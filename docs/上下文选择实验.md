# 上下文选择实验 · 0.2.0.dev2

## 本轮解决的问题

上一版先把全文检索结果装进 32,000 字符预算，再让模型排序。预算外的片段已经被排除，模型无法挑选。新流程先建立最多 100 条、有总字符上限的内部候选池，只给前 16 条做 cross-encoder 评分，再选择最终返回的完整记录。

开发比较后，当前候选使用重排名次融合权重 4、最终 128,000 字符预算。纯检索模式仍为 32,000 字符。两种预算单位都是字符，不是 tokens；较大上下文可能引入噪声，最终解题影响仍需独立实验。[平台的上下文规则](https://agentmemoryleaderboard.ai/api-guide)

## 开发结果与成本

每档仍是 63 道公开开发查询。历史关系和补丁只作为代理评价，不把当前目标补丁交给系统。

| 干扰/正例上限 | 流程 | Hit@1 | Hit@5 | 历史补丁部分取回 | 至少一份完整相关补丁 |
|---|---|---:|---:|---:|---:|
| 16 | 旧版，权重 1，32k 字符 | 80.95% | 98.41% | 93.65% | 92.06% |
| 16 | 新版，权重 4，128k 字符 | 84.13% | 100.00% | 100.00% | 100.00% |
| 64 | 旧版，权重 1，32k 字符 | 74.60% | 93.65% | 87.30% | 84.13% |
| 64 | 新版，权重 4，128k 字符 | 79.37% | 93.65% | 98.41% | 93.65% |

来源为 `results/dev7-selection-weights-noise16.json` 和 `dev7-selection-weights-noise64.json`。新旧流程使用不同的最终上下文预算，因此补丁覆盖改善不能全归于排序模型；平均返回文本也从约 28.8k 字符增加到约 90.2k 字符（64 档）。

权重 2 在 64 档的 Hit@5 更高，但 Hit@1 和 MRR 较低。权重 4 是当前兼顾排序与覆盖的开发选择，不是已证明的全局最优配置。独立验证的 8 题此前已用于检查旧模型，不能在反复查看后继续当作新的最终盲测。当次开发消融时 7 道封存查询尚未开启；随后冻结 0.2.0.dev2 完成首次验证，见 [封存集首次验证](封存集首次验证.md)。

## 移植和容量

`results/dev8-selection-port.json` 核对 8 个开发案例：真实 API 返回与预先完成的实验逐项一致，模型配对分数最大差为 0，所有返回片段保持原文。

启用模型的较大 HTTP 验证见 `results/dev8-capacity-http.json`：120 条公开历史轨迹、13,093 条消息逐条恢复，289 组跨 Add 配对；1,914 次健康检查成功、0 次错误；采样服务进程树 RSS 峰值 246,456,320 字节，约 235.0 MiB。写入共 575 次 Add，测试结束后自建进程全部回收。

这是 9 种语言的受限公开样本，顺序写入和查询，约 65 MB 原始 JSON。它还不能证明官方约 1.8B Tokens 规模、并发压力或现有云服务器的可用容量。

## 复现

开发消融可复用同一公开索引：

```powershell
.venv/Scripts/python.exe tools/selection_ablation.py --data C:/aml-public --index C:/aml-runs/rarity-01 --baseline results/repro-rarity.json --model-dir C:/aml-models/minilm --cache C:/aml-runs/pair-scores.sqlite3 --output results/selection-64.json --noise 64
```

较大样本先下载，再用新的工作目录启动测试：

```powershell
.venv/Scripts/python.exe tools/acquire_capacity_sample.py --data C:/aml-public
.venv/Scripts/python.exe tools/trajectory_http_probe.py --data C:/aml-public --receipt-name capacity-sample-receipts.json --work C:/aml-runs/http-large-01 --output results/repro-http-large.json --model-dir C:/aml-models/minilm --seconds 600
```

样本按固定 SHA 顺序选取，每种语言最多 20 条、每仓库最多 3 条；全部早于相应仓库的所有目标，排除目标轨迹。输入和输出都是公开研究数据，没有比赛私有轨迹。
