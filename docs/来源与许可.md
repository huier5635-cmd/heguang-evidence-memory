# 来源与许可

## 本项目

记忆存储、索引、消息规范化、接口及本地实验工具为本项目开发代码，使用根目录 MIT 许可证。技术路线使用 SQLite FTS5/BM25、RRF、压缩分块与内容寻址等通用方法。这里不把公共基准或模型称为自己的创新。

## 公开基准

| 来源 | 使用方式 | 许可声明与链接 |
|---|---|---|
| SWEContextBench，Jiayuan 等作者 | 公开历史问题/补丁、目标问题与作者关系标注，用于检索代理实验 | 数据集卡声明 MIT；[数据集](https://huggingface.co/datasets/jiayuanz3/SWEContextBench)、[作者仓库](https://github.com/jiayuanz3/SWEContextBench)、[论文](https://arxiv.org/abs/2602.08316) |
| VibeMemBench，Tongyi/AlibabaResearch 作者 | 初始 24 条、后扩至 120 条公开历史轨迹，研究消息结构并验证 HTTP 与归档；未运行其目标任务 Agent | 数据集卡声明 Apache-2.0；[数据集](https://huggingface.co/datasets/Tongyi-ConvAI/VibeMemBench)、[作者代码](https://github.com/AlibabaResearch/DAMO-ConvAI/tree/main/VibeMemBench)、[论文](https://arxiv.org/abs/2609.23570) |

以上数据来自上游真实软件仓库；其中代码片段还可能受原仓库许可证约束。当前开发包不重发原始代码、任务数据或轨迹。下载清单保留原始固定来源。

VibeMemBench 的 `scripts/memory_interface.py` 和 `scripts/memory_systems/demo.py` 用于理解历史消息契约；本项目独立实现消息归档与检索，没有复制它们的模型系统。所查文件 Git blob 分别为 `081c593af280830fbfe3c359965637f50e51ff79` 和 `f5b02d8184f058b225215f593b9c6358ae86e85c`。

## 可选重排模型

可选重排组件使用 [Sentence Transformers 的 cross-encoder/ms-marco-MiniLM-L6-v2](https://huggingface.co/cross-encoder/ms-marco-MiniLM-L6-v2)，模型卡声明 Apache-2.0。固定 revision `233902d25c440f23af6f7d6e94d2946bac0bee0a`，直接使用上游提供的 UINT8 AVX2 ONNX 文件，不另行训练。其权重不包含在本项目开发包内。

ONNX Runtime 用于本地 CPU 推理，Hugging Face Tokenizers 用于分词。仅用模型给问题与候选原文配对打分，不生成答案。模型能力、语言和截断限制见实验与复现文档。

## 本地编程开发模型

公开开发对照使用 [Qwen 官方 Qwen2.5-Coder-7B-Instruct-GGUF](https://huggingface.co/Qwen/Qwen2.5-Coder-7B-Instruct-GGUF/tree/13fb94bfda8c8cf22497dc57b78f391a9acb426a)，上游声明 Apache-2.0；推理由 [llama.cpp 官方 b11669](https://github.com/ggml-org/llama.cpp/releases/tag/b11669) 完成，llama.cpp 使用 MIT。模型权重和第三方运行包不在本项目包中。它们不属于参赛 Add/Search 组件。摘要、异常和实际失败见“本地模型对照”。
