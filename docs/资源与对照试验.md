## 已准备的对照工具

`prepare_paired_case.py` 只读取公开开发任务的可见字段，并从固定 Git 提交下载原始源文件；不会拿已在本机修好的代码当基线。每一条检索内容都重新核对为更早历史的原始字符区间。两组共享相同任务、原始源代码与指令，只在有记忆组添加历史记录，顺序按固定摘要决定。

准备命令：

```powershell
.venv/Scripts/python.exe tools/prepare_paired_case.py --data C:/aml-public --index C:/aml-runs/rarity-01 --case sympy__sympy-27868 --context-files sympy/parsing/mathematica.py --model-dir C:/aml-models/minilm --output C:/aml-runs/paired-plan.json
.venv/Scripts/python.exe tools/run_free_paired_codegen.py --plan C:/aml-runs/paired-plan.json --model cohere/north-mini-code:free --output C:/aml-runs/drafts
```

第二条默认只预览，不发生成请求。模型名称只是本轮目录可用的示例，实际调用前仍重新校验目录。

`research/free_codegen.py` 要求具名 `:free` 模型的输入、输出和请求价格均为零，并把路由最高价格设为零、关闭回退。遇到限流、费用未知或费用异常即停止，不买额度、不切到收费模型。密钥只从环境变量读取，不进入提示词、代码或日志。[价格路由契约](https://openrouter.ai/docs/guides/routing/provider-selection)

得到可用本地密钥配置并核实账户额度后，`--execute-public-requests` 才会发送两次公开任务请求。它只保存模型草稿，不自动应用或执行代码；当前助手还需要审核改动范围并冻结输出，再运行测试。现在没有自动化对照分数。

## 与参赛服务分开

这些外部模型仅供公开开发对照，不是学术参赛服务的 LLM 组件。生产服务仅使用全文检索和允许自由选择的 Reranker，仍不使用其他 Embedding 或 LLM。Full 继续受 `SUBMISSION_POLICY.json` 禁止；申请、开源、部署和 Smoke 已明确允许。
