# Qianora 专用密钥传输准备

这是待执行的操作说明，尚未传输新 Coding 密钥。只有取得“本编程服务专用 Token → agentmemoryleaderboard.ai，用于 Qianora 学术榜审核和 Add/Search / Smoke”的具体确认后执行。此授权不包括 Full。

原件保持在服务器 `/etc/heguang-coding.env`，root/0600。不得把明文放进命令助手输出、源码、本地文件、截图或聊天。也不得复用文本 Token、降低文件权限、增加取密钥公网接口或新增云账号登录凭据。

准备的 `work/coding-key-export-template.sh` 使用一次性 RSA-3072 公钥和 OAEP-SHA256。私钥只存在本次工具进程内存，不写文件。服务器用标准 OpenSSL 在内存中加密专用 Token，控制台只返回密文和非秘密传输标识，不改变原件权限。公钥和密文不提供服务器访问权限。

取得确认后的顺序：生成临时密钥对，把公钥写入本地非敏感执行脚本，经原有命令助手执行；读回密文时核对传输标识、公钥摘要和算法；仅在工具内存解密，直接填入官网类型为 password 的指定鉴权框；不输出明文、不写剪贴板或文件。若工具进程重置导致私钥丢失，旧密文作废，重新生成一对并重做，不能绕过加密。提交后的截图只保留掩码，清空工具内存中的凭据引用。

这是将既有密钥交给已获用户批准的收件方的传输机制；它不申请新权限，不创建新 API/SSH 凭据，也不改变现有文本服务。官网新的评测 Key 必须按同样保密要求处理。未获得具体确认时，停在密钥字段为空的申请草稿。
