## 执行顺序和限制

1. 再核对源码、模型成功记录、网站和文本服务配置校验值。与已审阅记录不符时停止。
2. 创建独立数据目录、保护环境文件和编程进程。资源上限为 384 MiB 内存、512 MiB 交换量、一个 CPU 核心的计算额度；每次只处理一个请求。
3. 进程启动前检查专用交换缓冲是否启用；如果主机重启后交换缓冲未启用，编程服务拒绝启动。此次不改 fstab，不能把本步骤写成主机重启后全自动恢复。

5. 安装编程版独立 29 天保留期任务。它不读取接口密钥，资源限额与 API 分开。
6. 上述检查通过且仍有资源余量后，备份当前 Caddy 配置，重新验证候选配置，原样保留文本处理段，仅增加 `/coding/`。重载后验证 HTTPS、公开健康、未鉴权拒绝、带鉴权搜索以及原文本接口。
7. 保存脱敏部署记录；不调用任何付费模型或评测接口。

失败时，恢复本次备份的网站配置，并停止、禁用新增编程 API 和清理定时器。保留新建文件、合成测试数据和受保护密钥供检查，不删除或覆盖旧文本数据。
