## 方法说明草案

独立实现的编程历史记忆服务。对原始消息、工具调用、补丁与命令输出建立每用户隔离的持久索引，保存原始内容与字符区间。正文、文件路径、符号分别检索并融合；技术特征按语料频率调整权重，再以固定本地 cross-encoder 重排候选。Search 返回原始证据，不生成目标答案。工具调用与结果仅依据同用户、同会话的明确 tool_call_id 配对，支持跨 Add 与重启。提供鉴权、幂等冲突处理、事务回滚、大请求准入与 29 天保留期。

检索实验、单机并发实验与单题代码对照均已披露，不能当官方分数。首次 7 题留出测试已有观察结果，不能继续作为新盲测；两轮本地代码模型对照均失败。引用和许可证见“来源与许可”；固定模型的许可与摘要另有记录。

## 申请前的实际核对

部署后记录固定 Commit、依赖、模型摘要和资源限制。分别从云内、外网验证 health、无凭据拒绝、带鉴权合成写入与搜索、重试、隔离和重启持久化；保存脱敏证据。核对文本服务和既有配置未变。确认 Coding 独立保留期任务成功。

完成这些事实后，按官网字段申请或绑定 Coding 版本。仅选择 Smoke，记录 Job/Run ID、状态与脱敏错误；失败可修复后重试。不要勾选或提交 Full 容量声明、正式提交复核或 Full 作业。具体接口与流程以[官方 API 指南](https://agentmemoryleaderboard.ai/api-guide)和[当期比赛说明](https://agentmemoryleaderboard.ai/competition/)为准。
