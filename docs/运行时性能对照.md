## 依据与控制

ONNX Runtime 的[线程说明](https://onnxruntime.ai/docs/performance/tune-performance/threading.html)区分算子内线程与算子间并行，并说明空转等待会消耗 CPU。其[图优化说明](https://onnxruntime.ai/docs/performance/model-optimizations/graph-optimizations.html)列出 Basic、Extended 和 Layout 等层级。这些只是实验方向，不能由文档直接推断目标服务器一定更快。

输入为此前端口一致性验证已使用的 8 道公开开发查询及 2 道合成查询，每个公开查询至多 4 份同仓库、严格更早的历史原文。目标答案、目标测试不载入。原文、token 窗口和评分聚合方式固定，每种设置重复两遍，模型分进程顺序运行，CPU 模型驻留不重叠。不保存查询/片段评分缓存；不调用官方接口或收费模型。
